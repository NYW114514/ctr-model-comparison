#### Project Structure

```
CTR_Project/
├── data/
│   ├── train.txt                        # Criteo raw data https://ailab.criteo.com/ressources/
│   ├── processed_data_full_optimized/   # Generated by preprocess.py
│   └── libsvm_data/                     # Generated by convert_to_libsvm.py
├── preprocessing/
│   └── preprocess.py                    # Raw data → npz chunks
├── traditional/                         # Traditional models (LR / FM / FFM)
│   ├── convert_to_libsvm.py            # npz → LibSVM/LibFFM format
│   ├── tune_traditional.py             # Hyperparameter search
│   └── train_traditional.py            # Train with best params + evaluation
├── deep/                                # Deep models (WDL, DeepFM, DCN, xDeepFM, AutoInt, PNN, FiBiNET)
│   ├── config.py                        # Global config (paths, hyperparams)
│   ├── data_utils.py                    # Data loading utilities
│   ├── model_factory.py                 # Model creation (baseline)
│   ├── model_factory_tune.py            # Model creation (tuning)
│   ├── train_utils.py                   # Training loop & evaluation
│   ├── train_all_models.py              # Baseline training entry
│   └── train_best_deep.py              # Train with best params + evaluation
├── docs/
│   └── tuning_results.docx
├── results/                             # Code output (auto-generated)
└── README.md
```

#### Environment

- Python 3.13.9 (Anaconda)
- PyTorch 2.10.0+cu130
- DeepCTR-Torch 0.2.9
- NumPy 2.3.5
- Pandas 2.3.3
- scikit-learn 1.7.2
- xlearn 0.4.4

#### How to Run

1. Data preprocessing

```bash
python preprocessing/preprocess.py
```

2. Format conversion (for traditional models)

```bash
python traditional/convert_to_libsvm.py
```

3. Traditional models

```bash
python traditional/tune_traditional.py
python traditional/train_traditional.py
```

4. Deep models

```bash
python deep/train_all_models.py
python deep/train_best_deep.py
```
